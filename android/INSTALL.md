# 小米 13 安装与使用

安装文件：**焊接识别-小米13-离线版-v1.0.0.apk**。

适用于小米 13（ARM64），最低 Android 8.0。模型已内置，安装后不需要电脑、服务器或网络。请预留约 250 MB 存储空间供应用和模型展开使用。

## 安装

1. 用 USB、文件传输或自己常用的方式，将 APK 复制到手机的“下载”文件夹。
2. 在手机文件管理器中点击 APK。若提示不允许安装，可为当前文件管理器临时开启“允许安装未知应用”，完成安装后再关闭该授权。
3. 安装后打开 **焊接识别**。第一次启动会准备本地模型，请等到显示“模型已就绪”。

本地签名安装包未上架小米应用商店；系统可能显示未知来源提示。若安装器显示具体错误，请保留完整错误内容，以便排查。

## 使用

1. 首次先点 **试用示例 → 开始检测**，检查模型是否能在手机上运行。
2. 点 **从相册选图**，选择焊接照片，然后点 **开始检测**。
3. 查看检测框、类别和置信度。红色为焊接不良，绿色为焊接良好，橙色为缺陷。
4. 下方显示可能原因和调整建议。可点 **补充现场现象**，人工选择烧穿、堆高、成形不对称等情况，筛选电流、速度、焊枪角度相关建议。
5. 点 **保存检测结果与报告**，选择 PNG 检测图、TXT 报告或 JSON 完整数据，然后在系统保存器中选择保存位置。

调整置信度阈值后需重新检测。更换图片会清空旧检测结果和人工选择的现象。界面旋转会保留当前页面；系统终止应用或重新启动后，请重新选图检测。

应用暂不支持实时摄像头检测。可先用手机相机拍照，再从应用相册入口选择。

## 结果与性能

识别在手机 CPU 上运行，实际耗时取决于手机温度和负载。大图按方向校正并采样到最长边不超过 1600 像素，检测模型输入为 640×640。JSON 坐标对应处理后的图片尺寸。

模型只有“焊接不良、焊接良好、缺陷”三类，不能直接测量电流、焊枪角度或行走速度。调整建议是需要结合现场现象核实的排查清单，不能作为已确认原因；未检出目标也不代表合格。
