CraftEye 数智评鉴系统 v2.1
Windows 10 / 11，64 位便携版

【启动】
1. 右键 ZIP 文件 → 全部解压，放到有写入权限的文件夹。
2. 打开解压后的文件夹，双击“启动网页.cmd”。
3. 浏览器会自动打开。首次加载模型可能需要稍等。

无需安装 Python、Node.js 或 Git，无需管理员权限。
不要在压缩包预览窗口中直接运行，不要只复制启动文件。
建议至少 8GB 内存、3GB 可用磁盘空间，浏览器使用 Edge 或 Chrome。

【综合分析】
本地图片检测无需联网。
综合分析、六维评分及建议需要联网调用通义千问。
首次使用：右上角“设置”→ 填写自己的 API Key。
接口地址、模型名称应与自己的百炼地域和工作空间一致。
网页输入的密钥仅保留在当前会话，关闭后需要重新填写。

需要本机长期保存时，将 .streamlit/secrets.example.toml 复制为
.streamlit/secrets.toml，再用记事本填写自己的密钥。
如果需要把本包继续转交别人，请先移除自己的 secrets.toml。
此发布包未包含开发者密钥和历史识别记录。

【摄像头】
进入“摄像头实时识别”，允许浏览器访问摄像头。
点击“截取当前结果”会停止摄像头并固定画面，再进行综合分析。
如果摄像头被其他程序占用，请关闭对应程序后重试。

【停止与再次打开】
双击“停止网页.cmd”可以关闭本包启动的网页服务。
关闭浏览器不会停止服务，重复双击启动文件会重新打开网页。
默认从 8501 端口开始；被占用时自动使用其他空闲端口。
只监听本机地址，不会自动向局域网公开服务。

【数据和日志】
新识别记录保存在 outputs 文件夹；启动日志在 logs 文件夹。
需要迁移自己的记录时，请在停止网页后复制整个包。
移动解压文件夹前应先停止网页。

【版本和组件】
附带已训练的 YOLO 模型、CPU 推理环境、页面资源和测试示例图片。
模型来源记录在 models/source.json，作者说明在 models/author-README.md。
随包保留依赖包许可证及 metadata；组件清单见 package-manifest.json。
网页不支持通过本包直接在 macOS、Linux 或 Android 上运行。
