# CraftEye v2.1 展示视频

90 秒，1920×1080，30 FPS，16:9。无字幕、无配音、无背景音乐；保留产品界面文字及片头片尾品牌名称。

## 镜头

| 时间 | 画面 |
| --- | --- |
| 0–6 秒 | 品牌开场 |
| 6–14 秒 | 系统首页 |
| 14–24 秒 | 裂纹识别结果 |
| 24–34 秒 | 59 分及关键缺陷限分 |
| 34–46 秒 | 六维雷达与分项评价 |
| 46–56 秒 | 改良建议及裂纹示例 |
| 56–66 秒 | 95 分优秀案例 |
| 66–76 秒 | 识别记录归档 |
| 76–84 秒 | 训练成长曲线 |
| 84–90 秒 | 品牌收尾 |

## 素材与真实性

使用本地真实识别记录 82、84 的图片、得分、各维度评价和改良建议，不重新调用云端，不生成虚构评分。摄制数据在 `outputs/showcase/history.sqlite3` 中独立备份，未修改生产记录。首页来自正在运行的真实网站。

结果镜头由 `capture_app.py` 复用项目界面组件展示已归档结果，属于历史结果演示，不是实时推理录像。数据库未保存完整的“图中现象”“可能原因”原文，故建议镜头仅展示已存储的缺陷类型、改良建议及项目自带裂纹参考图。成长曲线保留真实波动，记录来自多个测试样例，不能将其解释为某一学生训练后能力提升的证明。

## 预览

在本目录运行 `npm install`，然后 `npm run studio`，打开终端打印的地址，选择 CraftEye。时间线可以调整镜头顺序和长度。

导出：`npx remotion render src/index.ts CraftEye out/CraftEye-v2.1.mp4 --codec=h264 --crf=18`。

业务代码和评分算法没有因视频制作而修改。
